# 🏥 Hospital Management System

A user-friendly Hospital Management System website designed to simplify and manage various hospital activities through a modern web interface.

## 📌 About the Project

This project provides a digital platform for managing hospital-related information such as patients, doctors, appointments, medical records, and hospital services.

## ✨ Features
- 🔐 Login & Authentication
 - 📊 Admin Dashboard
- 🔍 Search and Filter
- 📊 About Hospital
- 👨‍⚕️ Doctor Management
- 🧑‍🤝‍🧑 Patient Management
- 📅 Appointment Management
- 📋 Medical Records
- 🏥 Hospital Services 
- 📞 Contact/Support Section
- 📱 User-friendly and responsive interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

The main purpose of this project is to create a simple and user-friendly
hospital management interface that helps organize important hospital information efficiently.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your web browser.
4. Right-click on page and select Open with Live Server.
5. The Project will open in your web browser.
